# Taste

## Communication
- Writes requests in Chinese; prefers to communicate in Chinese. Confidence: 0.7
- States requirements as short, high-level feature requests (a single sentence, no design detail) and leaves research, design and scope decisions to the agent rather than specifying them. Confidence: 0.55

## UI & Product
- Expects user-facing actions to be explicit and visible — e.g. a labelled Connect/Disconnect button on each list row — rather than left to unlabelled toggles or right-click menus whose meaning has to be guessed; pushes back when a feature is claimed done but has no discoverable entry point. Confidence: 0.6
